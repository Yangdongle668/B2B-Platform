## 当前文档范围

- 具体化描述符、依赖、服务/扩展点/端口、事务与事件语义，列出后台与公开接口的输入、并发、幂等、权限及审计要求。
- 保留全部已有 SQL DDL、模块分层、表前缀和停用属性；补齐状态机、站点过滤，明确无表的交付缓存及搜索索引结构。
- 补齐界面入口、36 个布局组件类型的模块归属、数据源注册 key、配置与异步任务、测试替身及每模块 14 条验收项（共238条）。组件属性仍由后续 component-schemas 实现并按系统设计校验。
- 用实际框架 Schema 校验 17 个描述符草案，并核对96个权限码、36个组件类型与234条后台端点设计；检查必填章节、命名、依赖环、权限和组件唯一性、事件与 ADR 引用及现有 Markdown 链接。前期仅做静态检查；本次正式评审已在MySQL8.4.11成功执行119个权威CREATE块，证据见正式评审报告。后续[M0复审](../reviews/m0-remediation-2026-10-20.md)补充最小后端及浏览器兼容验证；业务性能及并发协议测试仍待实现。

## 审查结论与开工前事项

完整的逐模块改进、检查依据和未决项见 [模块需求设计复审总结](../reviews/module-design-review-2026-10-20.md)。本轮新增56条接口设计，补足68条专项故障/一致性验收，并修正资源聚合标识、保存版本、里程碑与旧章节引用。

原复审列出的11项设计问题已补齐统一方案，详见[逐项处理与故障验收](../reviews/design-issue-resolution-2026-10-20.md)及平台框架4.10。7份新增ADR仍为Proposed，待评审冻结；通知权限名称与图谱集合版本方案已明确。各模块第14章保留原问题编号，继续跟踪评审、实现及验证。

| 阶段 | 已补齐的方案 | 状态 |
|---|---|---|
