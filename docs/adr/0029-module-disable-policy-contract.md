# ADR-029：站点模块停用策略与事务锁

| 项 | 内容 |
|---|---|
| 状态 | Proposed（待评审） |
| 日期 | 2026-10-20 |
| 决策者 | 架构负责人（待签审） |

框架5.2.5要求url/delivery读取停用路由策略，但SiteApi一直没有读取方法。候选增加moduleDisablePolicy(moduleId)，返回NOT_FOUND或REDIRECT及可空目标内容ID；未安装模块拒绝，空配置默认NOT_FOUND。配置与启停状态由core持有，业务模块不读sys_表。

启停属于短数据库事务，使用sys_site的排他行锁串行化同一站点的依赖检查、状态更新、回调、审计和事件登记。该锁随事务提交/回滚释放，避免有时限的sys_lock租约在回调尚未提交时失效。此项替换5.2.5原sys_lock示例；跨站点不互斥，不引入新表。所有启停入口必须使用此服务。

M0实现NOT_FOUND启停；REDIRECT读取契约先明确，实际设置须由后续路由用例验证目标内容存在、已发布且不属于待停用模块，并完成引用追踪。未接入验证前接口拒绝设置REDIRECT，不能写入无效目标后声称已支持301。
