# ADR-026：M0候选契约编译与基础值对象实现

| 项 | 内容 |
|---|---|
| 状态 | Proposed（待评审） |
| 日期 | 2026-10-20 |
| 决策者 | 架构负责人（待签审） |

## 背景

首次将框架第4章完整声明交给Java编译器，发现LocaleScope的静态unrestricted()与record同名访问器冲突；部分TYPE_USE空值注解放在限定类名之前；ReferenceSet、SemVer及ValidationResult仍包含示意方法体。graph及JobApi初始化还保留INSERT IGNORE与旧快照读取路径。

## 决策

候选版将LocaleScope静态工厂改为all()，保留boolean unrestricted()访问器；限定类型的空值注解移动到最后一个类型名称之前，语义不变。共享纯函数补齐可执行实现并覆盖边界测试。规范代码按框架第4章生成并校验，禁止在生成产物中另改签名。

graph按完整排序逐个排他upsert并当前读集合版本；JobApi幂等提交采用排他upsert及当前读，规范化参数不同拒绝。1213/1205必须回滚完整事务并由外层限次重试，不能在部分源写入后只重试一条锁语句。

这是尚未发布1.0.0的草案修正，不自动采纳其他ADR、不跳过G0或独立人工签审。

## 验证

完整API编译、共享纯函数测试、真实MySQL初始化并发与旧快照反例，结果记录到M0工程验收报告。

正式落地同时补齐框架5.8.5已声明但第6章缺失的sys_processed_event全局表；新增core V002，不修改已生成V001及原119个CREATE/3个ALTER。新表采用(consumer,event_id)自然主键、30天保留；清理不得删除仍有未完成投递的标记。此项补齐既有事件幂等设计，保持业务模块通过core开发支撑访问。

安全配置按框架5.14既有B2BWEB_*变量落地，不另创B2B_*产品配置。应用账号只有DML，模块/Flyway及Modulith Registry初始化由独立迁移账号完成；生产不在启动时执行DDL。恢复码统一采用128位随机数的32位十六进制、独立环境密钥HMAC-SHA256、行锁内单次消费；替换5.6.2旧“10字符/Argon2id”说明，与6.4.10一致，恢复码密钥不随SecretCipher密钥轮换。Registry的版本化技术DDL补入core V003，序列化载荷使用MEDIUMTEXT，避免库默认VARCHAR(4000)截断合法事件；保持原119块DDL不变。

编译后的Core实现继续发现框架4.1.3/5.2.5引用的@RequiresModuleEnabled没有可生成定义；RC在4.1.3补齐common包中的运行时类/方法注解，语义沿用既有规则，由Core切面检查当前站点，不允许提供方用空结果伪装停用状态。

模块骨架按3.4使用com.b2bweb.<id>直接子包；启动类置于com.b2bweb，使Modulith能识别全部17个模块。认证与统一错误实现归Core，应用装配层不开放Core内部包作为例外。技术支撑命名接口使用实测通过的core :: *语法，同时保留ArchUnit对core.support边界的限制。候选描述符仍表示未来1.0契约目标；构件保持0.1.0-SNAPSHOT，不因此标记为已发布或已验收1.0。

任务调度实现按既定5.9.2引入ShedLock 7.10.1（core与JDBC provider），使用既有sys_lock和数据库时间；不增加业务模块依赖。执行认领用sys_job.version作租约栅栏，心跳、检查点与调用方短事务一起持有排他行锁，旧worker不能提交进度或结果。任务文件写入使用真实ObjectStorage端口，不把内容放入任务JSON。

testkit复用文档所有者的版本化设置Schema作为构建资源，避免另外手写默认值；这不增加对业务模块Java实现的依赖。路由替身采用ICU4J 77.1进行确定性的Han/Latin转写，仍保留NFC本地文字策略；实际url模块的完整路由实现留在业务切片，不以替身代替提供方验收。

本地缺失业务服务通过显式Maven development构建配置加入testkit，普通生产构件只在test scope引用testkit。开发装配仅在local配置生效，通过API桥接真实站点/操作人/时钟；业务数据仍为进程内夹具，重启丢失。生产/预发布保护拒绝包含开发装配标记的构件，不依赖操作员是否记得关闭开关。

## M0共享搜索套件补充（2026-10-21）

真实Meilisearch和替身复跑发现attributesToRetrieve空列表含义不一致。候选契约明确：空表示默认全部字段，非空仅返回指定字段，`*`表示全部；适配器省略空的引擎字段，替身同样执行显式字段投影。共享套件验证脱离调用方可变对象、排序/分面、字段投影及代次游标，不能用目录覆盖代替行为一致性。仍待正式架构评审。
